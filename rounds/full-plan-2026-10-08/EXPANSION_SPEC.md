## Exact episodic history

At segment start the available state is (M,S,P), where M is compressed memory, S is an immutable CPU store of completed segments and P is an uncommitted prefix. Each retained event contains exact token IDs, per-token origin (observed_text, generated, scored_continuation), source locator, a stable sequential event identity and a content digest. Retained raw tokens have finite capacity C and FIFO eviction. Segment digest receipts persist until document reset. Explicitly identified input-chunk receipts persist for the entire stream, including across EOS, to make whole-chunk retries transactional. Their O(history) storage is measured and disclosed; the whole system is not constant-memory. Caller IDs identify sources but do not authenticate their truth.

For prediction row u, retrieval query is the last q tokens of x[:u], not x[u] or x[u:]. Rank prior events by the size of token-set intersection, breaking ties by recency. With an empty/no-match query the most recent events are returned. Return at most k events and R exact tokens, preserving each selected event's token order. Raw embeddings carry event rank, within-event position and origin. Selection is deterministic/non-differentiable; gradients flow through fresh embedding and reader attention only. No stale learned key tensors are cached. Retrieval is fixed throughout internal K steps. This is a simple lexical engineering alternative to learned kNN memory, not a reproduction of Memorizing Transformers/LongMem and not an originality claim.

The writer and store commit only after a full segment is consumed. Explicit chunk replay verifies its digest BEFORE prefix or writer mutation; identical IDs/content are no-ops and conflicts fail. Segment receipt IDs are the sequential ordinal in the current document; resets isolate documents. Generation returns a functional branch with generated provenance. Scoring a continuation labels it as conditional likelihood history, never as new external evidence. Serialization includes raw events, receipts, partial prefix/origins and clocks, and validates capacity, identity, digest and ordering before use.

Causal proof: S contains only earlier completed segments; query u is a deterministic function of x[:u]. Retrieved tokens therefore depend only on already available history and prefix. Pointwise retrieved attention at row u and causal reader/coda composition cannot depend on x[u:]. Offline full-segment and prefix inference produce the same selections at matching rows when the store, token provenance and parameters are the same. Training text is observed_text, a scored target prefix is scored_continuation, and free-generated history is generated; generated raw positions are excluded from retrieval by default. These deliberately different provenance policies do not imply unconditional teacher/free-generation parity. Additional information access relative to slots-only v0 is explicit and must be controlled.

## Semantic realization

An optional per-token plan z_u=tanh(W_z h_u) has dimension d_z<d. The separately callable realization function maps z (and only z) through its own projection, causal language network and vocabulary head. The plan has no direct raw-token, retrieved-memory, belief or workspace bypass. A plan snapshot can be saved/loaded and realized independently with matching checkpoint/context identity. This is a learned text-prediction bottleneck, not an identified semantic code or an annotated sentence-level plan. v0 coda remains available when the bottleneck is disabled.

## Legal dynamics

An optional fixed-depth core uses h_{r+1}=tanh(A h_r+b(E,M,retrieval)), A=c W/max(1,||W||_F), 0<c<1. For fixed forcing and real arithmetic, tanh is 1-Lipschitz and ||A||_2<=||A||_F<=c, so each causal row is a global c-contraction in its workspace. No recurrent attention/norm/residual bypass is allowed. b may contain causal evidence/history processing but cannot depend on evolving h. This is a restricted known contractive recurrent network, not equivalent to the v0 Transformer core. Diagnostics report the analytical bound and observed residual; floating-point outputs are not roundoff-certified. Fixed K remains the execution policy. Q01 and adaptive stopping stay unqualified; no local Jacobian estimate becomes a global certificate.

## Probability and training objectives

The main categorical text model remains p(x_u|M,S,x[:u])=softmax(realize(z_u)), or v0 readout when plan is disabled. CE/NLL is the sole likelihood for language/reasoning/realization. A separate optional predictive head q(f|M_t) is a normalized vocabulary distribution on the first token of the next segment in the same document, with supervised CE. The next token enters only this loss, never state or retrieval. Only existing eligible loss-mask targets count; no cross-EOS prediction and no context/gold-answer leakage. Normalize auxiliary summed CE by the same main eligible target count; report its own count/loss/weight. This finite surrogate does not estimate I(F;history|state) or prove sufficiency.

Compression is architectural capacity (slots/plan width/raw retention), not a KL on an arbitrary deterministic state and not a measured information rate. Compute is fixed K with real cost accounting, not a fabricated differentiable compute penalty. No unavailable action labels, ELBO or semantic target are added. These omissions follow the chosen probability/supervision object; they are not TODOs delegated to Local.
