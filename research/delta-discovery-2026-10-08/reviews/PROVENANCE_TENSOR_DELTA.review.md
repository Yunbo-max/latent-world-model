# Independent review — PROVENANCE-TENSOR-DELTA

Reviewer: `/root/orthogonal_value_audit`. Semantic/source review only; no editing or project execution.

Decision: **kill as a novel update/representation; retain as an identity-oracle control**.

- The immediate perturbation is exactly \(\beta(q^\top k)(r^\top c)e\), ordinary Delta under feature map \(k\otimes c\).
- One-hot codes are exactly routed independent Delta memories. This is the mandatory simplest control.
- Stable provenance is genuinely extra causal information when externally supplied; giving it only to this model would test information access, not tensor binding.
- Unique event tags require a query-side ID and an index. Without them, event retrieval remains underdetermined.
- Random/dense tags trade state for TPR/VSA crosstalk; exact orthogonality requires tag dimension at least the number of tags.
- Fast Weight Memory (arXiv:2011.07831) already uses a tensor-bound two-key address and residual fast-weight write; TPR, HRR/VSA, product-key memory and sparse episodic Delta cover the surrounding design space.

The remaining scientific question is whether externally meaningful provenance helps a task under equal-information controls. That is a task hypothesis, not a new Delta recurrence.
