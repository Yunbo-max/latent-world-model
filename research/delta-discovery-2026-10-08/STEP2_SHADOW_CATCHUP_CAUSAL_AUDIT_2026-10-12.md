# Step 2 residual object: shadow catch-up and crossed-world causal audit

Date: 2026-10-12  
Status: `lead/control`; `candidate_delta=0`; empirical effect unknown; no model code, training, inference, scoring, or experiment executed.  
Lineage: new Step-2 parent object informed by, but not a fourth revision of, exhausted R08 and R11.  
Formal change from the closed batch: the object changes the *action/measurement protocol* by retaining a lawful uncommitted branch or by resetting to the same pre-action state; it does not rename an updater coordinate.

## 1. Scientific question and exact scope

The remaining question is not whether another gate can be written. It is whether the effect of a candidate Delta write can be observed under a lawful, matched protocol before that write is treated as durable truth. The narrow object studied here is:

1. retain a candidate write as a low-rank shadow rather than modifying production state;
2. propagate the shadow exactly when the future transition is a shared action-independent affine map;
3. use an external target or a resettable evaluator to compare write/skip outcomes;
4. commit, abort, or keep waiting only from information available at that time;
5. charge all shadow, provenance, reset, evaluator, delay, and selection costs.

This is potentially useful as a mechanism-identifying audit or safety control. It is not yet a new Delta updater, a proof of better continual learning, or a claim of recursive self-improvement.

## 2. Formal object

Let the production state be \(S_t\in\mathbb R^{d_k\times d_v}\), with key-by-value convention. Here \(S_t\) is the exact baseline immediately before the candidate action; any decay at time \(t\) must already be included or explicitly ordered before/after the insertion. The standard candidate correction at that declared insertion point is

\[
e_t=v_t-S_t^\top k_t,\qquad
C_t=\beta_t k_te_t^\top=\ell_t r_t^\top,
\]

where \(\ell_t=\beta_tk_t\) and \(r_t=e_t\). The write/skip action is \(a_t\in\{1,0\}\). A pending shadow is not applied to production state. At future time \(u>t\), let the common transition be

\[
T_u(S)=A_uS+B_u,
\]

where \(A_u,B_u\) and all future inputs used to construct them are the same in the write and skip branches. For pure scalar-gated Delta without an intervening state-dependent feature change,

\[
A_u=I-\beta_uk_uk_u^\top
\]

with any declared decay composed in the actual implementation order rather than commuted through this factor.

The admissible information filtration \(\mathcal F_u\) contains the real prefix, production state, pending-shadow metadata, external observations already received, and charged evaluator results. It excludes future tokens, answer labels not yet observed, hidden validity oracles, and counterfactual outcomes that have not been generated by a lawful reset/twin/evaluator.

## 3. Exact single-shadow catch-up theorem

Define the write branch \(S_t^{(1)}=S_t+C_t\) and skip branch \(S_t^{(0)}=S_t\). Under the shared affine transition,

\[
S_u^{(1)}-S_u^{(0)}
=A_u(S_{u-1}^{(1)}-S_{u-1}^{(0)}).
\]

Hence, by induction,

\[
C_u:=S_u^{(1)}-S_u^{(0)}
=\Phi_{u:t+1}C_t,
\qquad
\Phi_{u:t+1}=A_uA_{u-1}\cdots A_{t+1}.
\]

Because \(C_t=\ell_tr_t^\top\),

\[
C_u=\ell_ur_t^\top,
\qquad
\ell_u=A_u\ell_{u-1}.
\]

The rank of one pending correction therefore remains at most one. At a stopping time \(\tau\), the retroactive catch-up operation

\[
S_\tau^{(0)}\leftarrow S_\tau^{(0)}+C_\tau
\]

reaches exactly the state that would have resulted from committing \(C_t\) at time \(t\). This requires the runtime to admit an arbitrary propagated low-rank additive patch or an equivalent lazy overlay; it is not generally a legal standard Delta residual update at time \(\tau\). Without that primitive, the theorem is representational only. For a shared query \(q_u\), the exact output difference is

\[
o_u^{(1)}-o_u^{(0)}=C_u^\top q_u=r_t(\ell_u^\top q_u).
\]

The operation catches up only the internal Delta state under the common action-independent suffix. It cannot restore outputs, actions, rewards, generated tokens, routing decisions, or environment effects that differed during \(t<u\le\tau\).

This proves a cheap conditional shadow *representation*. It does not prove a useful commit decision. Algebraically it is the one-overlay closure already isolated by R11 v3 and is also the forward sensitivity to a write amplitude. The new parent object is the paired measurement protocol built around that closure, not the closure itself.

## 4. Delayed current write is not retroactive catch-up

At time \(\tau\), applying

\[
\beta_tk_t(v_t-S_\tau^\top k_t)^\top
\]

is a new update against the *current* state. It generally differs from adding \(C_\tau=\Phi_{\tau:t+1}C_t\), which reconstructs the internal-state effect of having written at \(t\). A valid protocol must declare which intervention it evaluates. Treating them as interchangeable silently changes the estimand.

## 5. Paired local loss without write propensity

If a future target \(y_u\) is external, observed, and invariant to the memory action, and the two branches share the same \(q_u\), then both branch predictions and losses are computable from one observed common target and an exact model-based shadow prediction:

\[
L_u(a)=\ell\big(S_u^{(a)\top}q_u,y_u\big),\qquad a\in\{0,1\}.
\]

The paired local effect \(L_u(1)-L_u(0)\) is then a full-information *model-based* contrast, not two empirically observed closed-loop potential outcomes. It does not require randomized write propensity because neither model prediction is missing under the deterministic common-suffix/query/target, coupled-randomness, and exact-shadow assumptions. This is a stronger measurement object than endpoint-only QA, but it remains conditional on those assumptions.

If the memory action changes generated tokens, environment state, future \(k,v,q\), routing, gates, or the target itself, evaluating the shadow on the realized skip suffix computes the paired skip-suffix, NDE-form audit contrast

\[
Y^{1}(X^{0})-Y^{0}(X^{0}),
\]

not the closed-loop total effect \(Y^{1}(X^{1})-Y^{0}(X^{0})\). Population identification of this cross-world form needs an appropriate nested intervention/coupling or transport assumptions. A controlled direct effect instead fixes an external suffix \(x\) and compares \(Y(1,x)-Y(0,x)\). The closed-loop total effect needs a full twin/resettable environment or a separately justified randomized/sequential causal design.

## 6. Crossed-world Delta identity

Conditionally, suppose an offline audit/reset construction supplies two lawful worlds that reconverge to a verified-identical current state and query, while their histories imply evaluator labels \(y_0,y_1\). Their existence is an assumption to be established by a task-specific coupling/reset protocol; these labels are not available to the deployment updater before they are lawfully observed, and all acquisition/reset costs are charged. Save and cross the same candidate action \((\beta,k,v,e)\) in both worlds, with \(e=v-S^\top k\); regenerating a history-dependent candidate separately in each world defines a different estimand. Starting from common \(S\), compare skip

\[
S^{(0)}=S
\]

with write

\[
S^{(1)}=S+\beta ke^\top,
\qquad e=v-S^\top k.
\]

For a shared query \(q\), let

\[
d=\beta(q^\top k)e,
\qquad
L_w(a)=\frac12\lVert S^{(a)\top}q-y_w\rVert_2^2.
\]

Define the crossed improvement

\[
U_\times
=\frac12\left[(L_0(1)-L_0(0))+(L_1(0)-L_1(1))\right].
\]

Expanding the two squared losses cancels the shared quadratic \(\lVert d\rVert^2/2\) terms and the common base prediction, leaving

\[
\boxed{
U_\times
=\frac{\beta}{2}(q^\top k)e^\top(y_1-y_0)
}.
\]

Thus, in the shared-query squared-linear special case, the crossed audit isolates three necessary factors: query-key overlap, candidate residual direction, and the world-dependent target contrast. A write can strongly change an output yet have zero crossed faithfulness when any one factor vanishes. This is a measurement theorem, not a new update rule.

The cancellation is not valid when the two worlds or actions induce different queries, nonlinear downstream features, different base states, or different saved candidates. In that case the full \(2\times2\) crossing of histories and saved actions must be evaluated rather than replacing it by the boxed scalar identity.

## 7. What local verification does and does not identify

A resettable checker can identify whether a local alternative improves the checked source decision. It does not identify later transfer value. Two deployment populations can agree on every source-state check yet assign future target contrast \(+e\) versus \(-e\), reversing the sign of \(U_\times\). Therefore source-local verification must be accompanied by at least one of:

- observed reuse outcomes on held-out tasks;
- a declared transport/applicability assumption;
- a randomized or otherwise identified later-use selector;
- a conservative abstention certificate that counts false-release and missed-benefit costs.

A model self-score or self-generated future is not independent evidence of semantic validity.

## 8. Decision layer and old R08 boundary

Let \(W\) be the latent validity/applicability state and \(a\) a terminal action. Immediate Bayes risk is

\[
R_{\mathrm{now}}=\min_a\mathbb E[L(W,a)\mid\mathcal F_t].
\]

After buying evidence \(Y_j\) at cost \(c_j\),

\[
R_{\mathrm{acquire},j}
=c_j+\mathbb E\!\left[\min_a\mathbb E[L(W,a)\mid\mathcal F_t,Y_j]\mid\mathcal F_t\right].
\]

Acquisition is useful only when its expected risk reduction exceeds all evidence, delay, and shadow costs. With binary validity and affine terminal risks this reduces to R08's absolute signed-margin/EVSI identity. Therefore `acquire / abstain / commit` is not a distinct contribution. The shadow protocol can supply a particular paired loss channel under its strong common-suffix assumptions; it cannot manufacture validity evidence in an observationally equivalent pair of worlds.

For robust use, a declared ambiguity family \(\mathcal P_t\) replaces the inner expectation by a worst case, for example

\[
\inf_{\pi}\sup_{P\in\mathcal P_t}
\mathbb E_P\!\left[L(W,a_\pi(Y_j))+c_j\mid\mathcal F_t\right].
\]

A sequential Bellman form is time-consistent only under a suitable rectangular ambiguity set or an equivalent dynamic-consistency condition. Without a specified evidence channel and its cost, robust acquisition value is not computable; R08 v3's channel-free envelope remains the applicable abstention/no-information boundary rather than evidence for this new lead.

## 9. Failure boundaries and counterexamples

### 9.1 State-dependent future features

For nonlinear recurrence \(S_u=F_u(S_{u-1})\), the exact finite difference is

\[
C_u=F_u(S_{u-1}+C_{u-1})-F_u(S_{u-1}).
\]

A tangent shadow uses \(\widehat C_u=J_u\widehat C_{u-1}\), where \(J_u=DF_u(S_{u-1})\). If a compatible operator norm satisfies \(\lVert D^2F_u(z)\rVert\le M_u\) for every \(z\) on the segment joining \(S_{u-1}\) and \(S_{u-1}+C_{u-1}\), then

\[
\lVert C_u-\widehat C_u\rVert
\le \lVert J_u\rVert\lVert C_{u-1}-\widehat C_{u-1}\rVert
+\frac{M_u}{2}\lVert C_{u-1}\rVert^2.
\]

Hence a finite write is not generally recovered by a first-order trace, and later Jacobian products can amplify error.

A scalar counterexample is \(S_0=0\), candidate write \(k_0=v_0=\beta_0=1\), followed by a state-dependent \(k_1=S_0^+\), \(v_1=0\), \(\beta_1=1\). The true write branch returns to zero at the next step, while a base-path frozen shadow sees \(k_1=0\) and incorrectly preserves a unit difference.

### 9.2 Multiple pending writes

For \(m\) pending corrections,

\[
C_u=\sum_{i=1}^m\ell_{i,u}r_i^\top,
\qquad \operatorname{rank}(C_u)\le \min(m,d_k,d_v).
\]

When \(m\le\min(d_k,d_v)\), linearly independent left and right factors can attain rank \(m\). If each write must remain independently committable or abortable, its identity cannot be discarded; a direct low-rank ledger has the same asymptotic state. Fixed-rank recompression adds approximation error and may destroy per-item actionability.

Exact superposition further requires every candidate branch to share the same affine coefficients \(A_u,B_u\) at every later step. If committing any subset changes a later key, gate, router, coefficient, or injection, the common linear propagation no longer represents all subset branches exactly.

### 9.3 No-information worlds

If two worlds induce the same distribution over every allowed \(\mathcal F_\tau\) observation but require opposite write/skip actions, every selector takes the same action distribution in both. Under 0--1 action loss and an equal mixture of the two worlds, every selector has average error at least \(1/2\), hence error at least \(1/2\) in one world. More generally, no selector improves the Bayes envelope without additional identifying information; positive-cost waiting can be strictly worse. Shadowing measures state effects only when an external outcome is available—it cannot reveal which observationally equivalent semantic world is true.

## 10. Information, state, and computation cost

For one exact affine shadow, the factor state is \(O(d_k+d_v)\) reals plus candidate time, key/value/residual provenance, coefficient version, normalization convention, evidence status, timing, precision, and commit policy. A general dense \(A_u\) costs \(O(d_k^2)\) to apply to \(\ell_{u-1}\). For the pure Delta factor,

\[
\ell_u=\ell_{u-1}-\beta_uk_u(k_u^\top\ell_{u-1}),
\]

the factor update is \(O(d_k)\) per shadow and the query correction is \(O(d_k+d_v)\) if the output vector is materialized. Materializing \(C_\tau\) into dense \(S_\tau\) costs \(O(d_kd_v)\); keeping a lazy overlay avoids that immediate write but adds read and future-update overhead. With \(m\) live shadows, state and work scale at least linearly in \(m\) absent additional structure. Coupled branch evaluation and all external evaluator/reset costs are additional.

A full closed-loop twin copies the complete recurrent/network/environment state and computation. A resettable external checker additionally pays snapshot/reset, alternative generation, evaluator, and selection costs. Offline selector training and construction-time checks must not be omitted from matched-cost comparisons.

## 11. Strong same-information controls

| Control | What it matches | Discriminator required for this lead |
|---|---|---|
| direct pending-write ledger | same low-rank factors, provenance, later evidence | shadow must reduce cost or improve an identifiable audit, not merely rename the ledger |
| full state/environment twin | exact closed-loop branch under reset/simulation | low-rank shadow must remain exact under a useful weaker condition |
| direct predictor of `Q(write)-Q(skip)` | same prefix/evidence and terminal action | when supplied the same paired evaluations it has the same labels; shadow must show matched-information statistical-efficiency, calibration, or total-cost advantage |
| randomized action plus OPE/DR | identified observed total effect under stated assumptions | paired branch must avoid exploration variance/cost without changing estimand |
| checkpoint/undo log | recoverable mutation | shadow must count lost-coordinate and replay cost and distinguish rollback from causal effect |
| SafeCommit-style probe/certificate | commit/probe/fallback from plausible worlds | Delta trace must add a distinct, correctly costed certificate object |
| MemTX-style staged belief | staging, validation, provenance, repair | internal shadow must add more than transactional lifecycle semantics |
| external authoritative KV/retrieval | preserves raw evidence outside compressed Delta state | any internal-memory benefit must survive equal storage and access budget |

## 12. Testable predictions and measurement status

The object predicts:

1. On a teacher-forced or externally supplied common suffix, the factor-propagated shadow and a full duplicated Delta state agree exactly up to numerical precision.
2. When one future key/gate/router depends on the branch state, the common-path shadow error grows with the missing curvature/coupling term and may reverse the estimated write benefit.
3. Crossed-world action sensitivity can be high while \(U_\times\le0\); action change alone is therefore not faithfulness.
4. Locally verified corrections can harm later tasks when applicability/transport is wrong, even when the source checker is perfect.
5. Pending-shadow count grows with unresolved evidence arrival; a fixed-rank implementation must either lose independent decisions or accumulate measurable approximation error.

Existing public assets cover pieces, not the full claim. Resettable executable tasks can measure local paired action effects; counterfactual memory audits can cross histories and actions at an identical present; staged-memory systems test transactional safety. No audited public protocol found in this pass jointly exposes an internal Delta write action, lawful paired or propensity-identified delayed outcome, old-capability retention, later-learning effect, and all matched costs. The joint native measurement gap therefore remains open.

## 13. Decision

This pass preserves a useful theorem/debug package:

- exact single-shadow catch-up under shared action-independent affine dynamics;
- strict distinction between delayed current write and retroactive effect;
- exact crossed-world Delta alignment identity in the squared-linear case;
- explicit direct-effect versus closed-loop total-effect boundary;
- nonlinear tangent-error recurrence, rank-growth boundary, and full cost controls.

It does not create an active candidate. The algebra overlaps R11; the decision layer overlaps R08 and controlled sensing; staging overlaps transactional memory, SafeCommit, and MemTX; reset-based local counterfactual checking overlaps CounterMem; crossed-history action audits overlap CMA. The remaining potential contribution is a Delta-specific *mechanism-targeted, model-based audit lead* under the exact branch assumptions if a native lawful object and matched-cost advantage can be established. Originality and identification beyond those assumptions both remain unresolved. Until then:
