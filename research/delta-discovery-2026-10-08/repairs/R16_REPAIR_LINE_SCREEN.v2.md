## Decision

The second attempt yields a useful exact theorem and a certified approximation contract. The true invariant-subspace dimension of the frozen matrix-function correction is the number of distinct Lambda eigenvalues on which the current key has nonzero projection. A small value permits a small DPR1 core, but cheap projection/lifting additionally requires diagonal tied coordinate groups or an explicitly supplied fast fixed eigenbasis. A dense unknown eigenbasis retains transform/discovery costs; a dense key under distinct per-channel decay gives the v1 worst case.

This is not a new self-improving updater. The endpoint map is still the R09/PDN/RLS normalized oblique edit, the grouped generator is an added modeling restriction, direct implementation is identical, compact chunk-scan closure is absent, and no new evidence says which memory should be revised. R16 is therefore parked after substantive attempt 2/3 as a conditional theorem/control with zero active, admitted, or selected candidates.

Reopen attempt 3 only with either (i) independent evidence for the simultaneous grouped generator plus a matched-total-cost advantage unavailable to direct grouped KDA/DPLR/exponential-action controls, or (ii) new causal information that resolves protection versus revision without future leakage.
