# R18 v3 — bounded-fiber leakage ledger for destructive Delta writes

Status: **conditional theorem/debugging control; parked after the final substantive attempt 3/3; not an active D candidate**. This versioned child preserves the exact bytes, counterexamples and reviews of R18 v1/v2. It repairs one target mismatch rather than deleting the v2 no-go: when the exact common invisible subspace collapses to zero, a useful question is not whether an exact quotient can be renamed into existence, but how many side coordinates are sufficient to bound the remaining protected-path discrepancy over the state fiber that a destructive write merges.

The result is an exact finite-tree min--max formula, a computable conservative PSD-envelope certificate, and an explicit boundedness boundary. It does not establish global nonlinear congruence, produce a prefix-valid branch tree, prove an advantage over a direct ledger, or establish novelty over switched-system observability and balanced truncation.

## 1. Lineage and formal object

Use the complete prewrite state `x in R^n`. A destructive affine update and the protected reference entrance are

\[
z=Ax+a,\qquad y_0=Px+p. \tag{1}
\]

Let `K in R^(n x m)` have orthonormal columns spanning `ker A`. States `x` and `x+K alpha` are therefore merged by the update. Their protected reference difference at the continuation entrance is

\[
u_0=L\alpha,\qquad L:=PK. \tag{2}
\]

As in v2, condition on a declared prefix-measurable finite continuation tree. Along a path
`pi=(e_1,...,e_h)`, edge `e_j` has linearized transition `J_(e_j)` and read map `C_(e_j)`. The affine offsets cancel in a paired state difference. With nonnegative read weights `w_j`, define

\[
T_{\pi,j}=C_{e_j}J_{e_{j-1}}\cdots J_{e_1}L, \tag{3}
\]

where the product before the first read is the identity, and stack

\[
Z_\pi=
\begin{bmatrix}
\sqrt{w_1}T_{\pi,1}\\
\vdots\\
\sqrt{w_h}T_{\pi,h}
\end{bmatrix},
\qquad
G_\pi=Z_\pi^\top Z_\pi\succeq0. \tag{4}
\]

The exact paired protected-output energy generated by the merged coefficient `alpha` is

\[
E_\pi(\alpha)=\|Z_\pi\alpha\|_2^2
=\alpha^\top G_\pi\alpha. \tag{5}
\]

V2's exact common invisible coefficient space is precisely

\[
\mathcal N_{\rm exact}=\bigcap_\pi\ker Z_\pi. \tag{6}
\]

When (6) is `{0}`, exact zero-leakage compression of every merged direction is impossible. V3 keeps that conclusion and changes the target to an explicit nonzero error budget under an explicit fiber-radius assumption.

## 2. Rank-r side ledger and exact residual ambiguity

Choose `V in R^(m x r)` with `V^T V=I_r`. Store the side code

\[
M_Vx=V^\top K^\top x. \tag{7}
\]

The augmented post-write representation is `[Ax;M_Vx]`. If two states have the same augmented representation, their coefficient difference lies in

\[
\operatorname{im}P_V,
\qquad P_V:=I_m-VV^\top. \tag{8}
\]

This is exact for an unquantized real side code: `M_VK alpha=V^T alpha`, so the ledger preserves the coefficient component in `span(V)` and merges the orthogonal component. A finite-bit or noisy code has larger fibers and needs an added cell-diameter/noise term; equations (8)--(12) do not silently cover quantization. For one fixed destructive map, the construction adds `r` side coordinates per encoded state plus `K`, `V`, their precision/normalization and any refresh metadata; those costs are not free. Reusing a fixed-width code across successive, differently oriented destructive maps additionally requires a sufficient code-transition/transport rule, which is not supplied here.

Use the endpoint convention `sigma_(m+1)(Z_pi)=lambda_(m+1)(Gamma)=0`; equivalently, the spectral-tail formulas below apply for `0<=r<m`, while the full ledger `r=m` has `P_V=0` and zero residual leakage.

Assume the **pairwise coefficient difference** within every admissible same-augmented-state fiber obeys the declared bound

\[
\|\alpha\|_2\le R. \tag{9}
\]

This is not merely a bound on each state's individual coefficient norm: that weaker statement permits pairwise radius `2R`. Then, for a fixed path and ledger,

\[
\sup_{\substack{\alpha\in\operatorname{im}P_V\\\|\alpha\|\le R}}
E_\pi(\alpha)
=R^2\lambda_{\max}(P_VG_\pi P_V). \tag{10}
\]

The equality follows from the Rayleigh quotient restricted to `im P_V`; a top eigenvector attains it. Taking the worst allowed path gives the exact robust residual leakage

\[
\boxed{
\sup_{\pi}\sup_{\substack{\alpha\in\operatorname{im}P_V\\\|\alpha\|\le R}}
E_\pi(\alpha)
=R^2\Lambda(V),
\quad
\Lambda(V):=\max_\pi\lambda_{\max}(P_VG_\pi P_V).}
\tag{11}
\]

Thus the optimal common rank-`r` side ledger is the Grassmann min--max problem

\[
\boxed{
\Lambda_r^*=
\min_{V^\top V=I_r}
\max_\pi\lambda_{\max}(P_VG_\pi P_V).}
\tag{12}
\]

This is a formal object, not an assumed eigentruncation. For every path, the best path-specific rank-`r` subspace has residual `sigma_(r+1)(Z_pi)^2`; forcing one common `V` can only be worse. Hence

\[
\boxed{
\max_\pi\sigma_{r+1}(Z_\pi)^2\le\Lambda_r^*.}
\tag{13}
\]

Consequently, a necessary condition for a worst-case budget `tau` is
`R^2 max_pi sigma_(r+1)(Z_pi)^2 <= tau`. It is not sufficient because the individually optimal path subspaces can disagree.

## 3. Computable common-envelope certificate

The nonconvex problem (12) can be upper-bounded by any common PSD envelope

\[
\Gamma\succeq G_\pi\quad\text{for every allowed path }\pi. \tag{14}
\]

For example, one may choose a trace-minimizing SDP envelope. This choice is objective-dependent: the PSD partial order need not have a unique least upper bound for noncommuting matrices. Let `V_r` be any top-`r` eigenspace of a chosen `Gamma`. Then

\[
\begin{aligned}
\Lambda(V_r)
&=\max_\pi\lambda_{\max}(P_{V_r}G_\pi P_{V_r})\\
&\le\lambda_{\max}(P_{V_r}\Gamma P_{V_r})\\
&=\lambda_{r+1}(\Gamma). \tag{15}
\end{aligned}
\]

Therefore

\[
R^2\lambda_{r+1}(\Gamma)\le\tau \tag{16}
\]

is a computable sufficient certificate for the rank-`r` ledger. The smallest `r` satisfying (16) is a certified width for the chosen envelope, not necessarily the minimum width for (12). The envelope may be conservative even when it is optimal for its own SDP objective.

### Complementary-world witness

Let `m=2` and two lawful same-prefix paths have

\[
G_A=e_1e_1^\top,
\qquad G_B=e_2e_2^\top. \tag{17}
\]

Exact zero leakage requires `r=2`. For `r=1`, write the preserved unit vector as `v=(cos theta,sin theta)`. The unpreserved unit direction is `v_perp=(-sin theta,cos theta)`, so

\[
\Lambda(v)=\max\{\sin^2\theta,\cos^2\theta\}\ge\tfrac12. \tag{18}
\]

Equality is attained at `theta=pi/4`; hence `Lambda_1^*=1/2`. In contrast, the trace-minimizing common envelope of (17) is `Gamma=I`, whose degenerate top-eigenspace certificate has `lambda_2(Gamma)=1`. The envelope safely certifies residual one but misses the exact robust optimum one-half. This witness prevents us from relabeling (15) as the solution of (12).

## 4. Boundedness, prefix coverage and nonlinear boundaries

The pairwise radius in (9) is indispensable. If `Lambda(V)>0` and `alpha` is unbounded, scaling a nonzero leaking direction makes (11) arbitrarily large; no finite absolute budget exists. A lawful alternative must state a finite pairwise radius, finite precision/range, a distributional moment or tail contract, or demand exact zero leakage. A real-valued state dimension alone is not a finite-bit capacity claim.

The path family is also part of the contract. If an event `C_t` says the prefix-issued tree contains the realized continuation and

\[
\Pr(C_t\mid\mathcal F_t)\ge1-\delta, \tag{19}
\]

then (11)--(16) hold for the realized path on `C_t` when (9) is a deterministic domain restriction. If the radius is estimated or stochastic, its own coverage event must be intersected with `C_t`, and the failure probabilities must be composed. Reusing the claim over multiple writes needs joint or anytime failure accounting. Marginal branch frequencies, exchangeability or average calibration cannot silently become pointwise conditional coverage for every prefix.

Equations (3)--(5) are exact for the declared affine tree and paired exogenous path. A Jacobian construction is only local for a nonlinear state-dependent router. A global finite-edit guarantee needs finite differences or a uniform remainder bound over the actual same-update fiber, plus proof that the two trajectories retain the same allowed routing semantics. V3 does not close that congruence problem.

## 5. Delta specialization and controls

For a unit key and post-decay Delta overwrite with `beta=1`, condition on the same current exogenous input/features and hold the generated `k`, `v` and `beta` common across the paired states:

\[
S^+=(I-kk^\top)\bar S+kv^\top, \tag{20}
\]

the memory-only state map erases the `k` row of every value channel. With an invertible pre-decay map, the erased preimage has the corresponding `D^{-1}k` direction per value channel, so `m` is at least the value width unless other complete-state cancellations change the kernel. If `k`, `v` or the gate itself depends on the paired state, this memory-only kernel need not survive: for example a state-dependent `v(x)` can re-encode the allegedly erased scalar. The coefficient basis must then be derived from the complete ordered joint map/Jacobian or finite map; it cannot be inferred by commuting decay and overwrite.

For `0\le beta<1`, the post-decay erase factor `I-beta kk^T` is invertible. Literal quotient loss from that factor disappears only when the decay and the relevant complete-state map are also injective; a singular `D` or another full-state block can retain a nontrivial kernel. Under the injective case the question changes into conditioning and attenuation, so ordinary scalar Delta gating is a mandatory comparator, along with:

1. the full direct coefficient ledger `K^T x` (`r=m`, zero leakage);
2. a task-specific direct protected-coordinate ledger when fewer coordinates are already known;
3. v2's exact recursive common kernel when it is nontrivial;
4. the exact robust optimizer (12), the common-envelope certificate (15), and path-specific SVDs as distinct objects;
5. full JVP/VJP or finite-difference tracing for the same branch family;
6. the R17 action-specific residual gate, which bounds one actual write rather than every pair in a merged fiber.

R17 and R18 therefore share spectral machinery but not the estimand. R17 asks how much one realized Delta action moves a frozen continuation. R18 asks what side information is needed so all bounded pairs merged by a destructive update remain behaviorally close over every allowed path.

## 6. Cost and information access

Let the coefficient dimension be `m`, the number of enumerated paths `B`, and the maximum horizon `H`. Propagating all `m` threatened directions through a tree requires the relevant transition/read products or equivalent Jacobian-vector products. Explicitly storing all path Gramians costs `O(Bm^2)` real scalars; traversal cost also depends on branch sharing and the underlying state transition. Solving (12) is a nonconvex robust-subspace problem. A common-envelope SDP is only a certificate and may itself be more expensive than storing a direct ledger.

For one fixed destructive event, a dense fixed ledger stores `r` side coordinates but also needs the bases: dense `K,V` contain `nm+mr` real entries, and naive encoding by `V^T K^T x` costs up to `O(nm+mr)`. Reusing the code recurrently across multiple destructive events requires an explicit sufficient side-code transition; simply appending each new code grows state, while overwriting an old code can lose earlier erased information. An adaptive prefix-specific ledger additionally needs basis refresh/transport, alignment metadata and a causal proof that old stored codes remain interpretable. Bit precision, quantization-cell error, normalization, numerical safety margin, predictor/calibration state and memory traffic must be charged. Float dimension alone is not matched-total-cost evidence.

The construction uses no future answer or old-knowledge-validity oracle at write time if the path/envelope certificate was lawfully issued from `F_t`. Building or calibrating that certificate from historical continuations is an offline information cost. Directly learning a scalar gate from the same prefix and a direct ledger built from the same branch traces are same-information controls.

## 7. Predictions, counterexamples and measurement gap

The theorem yields falsifiable conditional predictions:

1. under the declared affine tree and radius, the worst residual energy for a fixed `V` equals, rather than merely lies below, `R^2 Lambda(V)`;
2. if all `G_pi` share a common top-`r` eigenspace and the envelope is tight there, the envelope construction can meet the min--max optimum; complementary directions such as (17) create a strict gap;
3. doubling `R` quadruples the certified energy, while omitting any radius makes a nonzero-leakage absolute guarantee impossible;
4. if `r=m-dim(N_exact)`, preserving the orthogonal complement of the exact common invisible space gives zero leakage; smaller width may still meet a nonzero budget;
5. an observed violation must come from a false tree/pairwise-radius contract, quantization/noise omitted from the exact-real theorem, a nonlinear/routing remainder, numerical error, a convention/order error, or an incorrect implementation—not from looseness of the equality (11).

The existing native bAbI, LAMBADA, RULER, BABILong and LongMemEval assets expose endpoint tokens/answers and native scores. They do not expose paired states differing by a controlled `K alpha`, the path maps `Z_pi`, the fiber radius, the ledger rank, conditional tree coverage, or a matched-total-cost full ledger/no-write control. Endpoint changes could test a future system, but cannot natively identify equations (11)--(16). An instrumented same-fiber intervention trace would be a new measurement object; none is fabricated here.

## 8. Nearest work and terminal disposition

The mathematical ingredients are strongly covered: observability and unobservable subspaces for switched systems; approximate bisimulation under incremental stability; balanced truncation and Hankel/Gramian singular directions; common Lyapunov/Gramian inequalities; robust subspace optimization; and direct sufficient-coordinate ledgers. V3's retained value is a Delta-specific debugging bridge between exact quotient failure and a bounded-error side-channel budget, with an exact min--max formula and a witness separating robust optimization from a convenient PSD-envelope certificate.

That is useful one-event/fixed-map representation theory, not a scientifically admitted new updater. Prefix-valid tree/radius construction, global nonlinear congruence, a constant-width recurrence for repeated destructive writes, finite-bit error control, an implemented decoder that actually consumes the side code, matched-total-cost superiority, native mechanism measurement, broad originality and empirical effect remain open. The direct ledger and scalar gate are strong simpler controls.

**Decision:** park and close R18 after substantive attempt 3/3. Candidate, scientific-admission and selection increments remain zero. Reopen only with genuinely new evidence: a causally available path/radius contract under shift, a global nonlinear or finite-difference closure, a matched-cost advantage over direct storage/gating, and a native mechanism-identifying measurement. Changing rank, radius, SDP objective, threshold or eigensolver is not a new repair.
