# R18 v2 — prefix-causal robust recursive quotient for exact Delta overwrite

Status: **conditional theorem/debug control; attempt 2/3 parked; not an active D candidate**. This child preserves R18 v1 and repairs its earliest open premise. R18 v1 computed the recursively closed quotient from a realized future suffix. That is valid as a retrospective audit but is not a lawful online certificate at the current write. R18 v2 replaces it by a prefix-measurable uncertainty tree, proves the exact affine robust recursion without rectangularizing path constraints, and shows when the lawful quotient necessarily collapses to retaining the full threatened state. The result remains covered by switched-system observability, common invariant subspaces, predictive equivalence/right congruence and direct sufficient-coordinate ledgers.

## 1. Original failure and precise patch

Let the complete pre-write state be

\[
x_t=(\operatorname{vec}S_t,r_t)\in\mathbb R^n,
\]

and let the complete current update and protected reference entrance be the affine maps

\[
z_t=A_tx_t+a_t,\qquad x_t^{ref}=P_tx_t+p_t,\qquad
K_t\text{ spans }\ker A_t. \tag{1}
\]

For fixed unit key `k`, invertible decay `D`, exact overwrite and no auxiliary copy, the memory contribution to `ker A_t` is the familiar set

\[
\{\operatorname{vec}(D^{-1}ka^\top):a\in\mathbb R^{d_v}\}. \tag{2}
\]

The complete kernel must still include current updater/side-state paths and cross-block cancellations, as in R18 v1. The reference entrance `P_t` says which pre-write behavior is protected (for example, post-decay but pre-overwrite); replacing it by the destructive map would make erased behavior invisible by construction.

At action time the available information is a sigma-field `F_t` generated by the lawful prefix. The patch requires an `F_t`-measurable finite rooted tree `T_t`: its topology, every outgoing set `A(eta)`, and every numeric matrix/vector below must be fixed by the prefix or a declared prefix-time model. At a tree node `eta`, each outgoing edge `a in A(eta)` declares a complete-state affine transition and read

\[
x_{\eta a}=J_{\eta,a}x_\eta+b_{\eta,a},\qquad
y_{\eta,a}=C_{\eta,a}x_\eta+d_{\eta,a}. \tag{3}
\]

The branch family must be fixed across each current-update fiber; otherwise choosing a different tree for two states merged by `A_t` encodes lost state or a hidden future oracle. The actual continuation must be a path in this declared tree for the exact robust claim. If the tree is learned, define the deployment event `E_t={realized suffix path in T_t}` and require `P(E_t | F_t)>=1-delta` almost surely, with calibration randomness separated from the deployment suffix. Every guarantee below is conditional on `E_t`; marginal population coverage alone is weaker and does not protect a particular prefix.

The tree must preserve path compatibility. Replacing it by an independent marginal mode set at every depth silently allows mode words that were not in the original family. That rectangularized construction is sufficient but can be strictly too conservative.

## 2. Exact path-conditioned backward recursion

For every node `eta`, let `B_eta(x)` denote the stack of all declared future affine read differences along every suffix below that node. Offsets cancel when comparing two states, so only the linear part matters. Define

\[
\mathcal N_\eta={u:B_\eta u=0\}. \tag{4}
\]

At a true graph leaf there is no further edge-read, so, with the empty-intersection convention,

\[
\mathcal N_\eta=\mathbb R^n. \tag{5}
\]

and at an internal node,

\[
\boxed{
\mathcal N_\eta=
\bigcap_{a\in A(\eta)}
\left[\ker C_{\eta,a}\cap J_{\eta,a}^{-1}\mathcal N_{\eta a}\right].}
\tag{6}
\]

Proof is by induction on remaining depth. A perturbation `u` is invisible on edge `a` now exactly when `C_(eta,a)u=0`, and it is invisible after that edge exactly when `J_(eta,a)u` lies in the child invisible space. It must satisfy both statements for every lawful outgoing edge. Conversely those conditions make every read difference zero on every lawful descendant path. Hence (6) is the maximal subspace invisible to all paths represented by the tree.

This path-conditioned recursion is necessary for exactness. Consider two allowed length-two paths with zero root reads. On path A use root transition `J_A=I` and child terminal read `e_1^T`; on path B use the coordinate-swap root transition `J_B` and child terminal read `e_2^T`. Both compositions read only `x_1`, so the exact common invisible space is `span(e_2)`. If one discards path pairing and independently combines the marginal transitions with both next reads, the cross-combinations shrink the result to `{0}`. That rectangular hull certifies safety but falsely rules out a real quotient. Taking a union or an existential-mode kernel has the opposite error and is unsafe.

Let `O_T` be the stacked linear map of all declared tree reads from the reference root, so `ker O_T=N_root`, and let `Phi_T(x_t)=O_TP_tx_t+constant`. The exact finite-tree affine decodability theorem is

\[
\boxed{\exists g:\Phi_T(x_t)=g(A_tx_t+a_t)
\quad\Longleftrightarrow\quad
\ker A_t\subseteq\ker(O_TP_t).} \tag{7}
\]

This follows from the linear factorization criterion: `Phi_T(x)-Phi_T(x')=0` for every pair merged by the current update iff every vector in `ker A_t` is annihilated by `O_TP_t`. Equivalently there exists `L` with `O_TP_t=LA_t`. Equation (7) is recoverability of the declared old behavior, not proof that the deployed path invokes the decoder or that the edited fact is semantically valid.

Choose full-row-rank `Q_eta` with `ker Q_eta=N_eta`. Equation (6) gives `N_eta subseteq ker C_(eta,a)` and `J_(eta,a)N_eta subseteq N_(eta a)`, hence there exist edge-specific quotient maps satisfying

\[
C_{\eta,a}=\bar C_{\eta,a}Q_\eta,\qquad
Q_{\eta a}J_{\eta,a}=\bar J_{\eta,a}Q_\eta. \tag{7a}
\]

Thus `q_eta=Q_eta x_eta` obeys the causal recursion

\[
q_{\eta a}=\bar J_{\eta,a}q_\eta+Q_{\eta a}b_{\eta,a},\qquad
y_{\eta,a}=\bar C_{\eta,a}q_\eta+d_{\eta,a}. \tag{7b}
\]

Its width is `rank Q_eta=n-dim N_eta`. It is the minimum width among linear prefix statistics preserving all lawful descendant reads: if `Tx_eta` generates those reads, every row of their stacked operator lies in `row T`, so `row Q_eta subseteq row T` and `rank T>=rank Q_eta`.

## 3. Stationary all-horizon fixed point

For a finite stationary rectangular mode family `Sigma`, where every mode can legally follow every other mode, define

\[
V_0=\bigcap_{\sigma\in\Sigma}\ker C_\sigma,
\qquad
V_{r+1}=V_0\cap\bigcap_{\sigma\in\Sigma}J_\sigma^{-1}V_r. \tag{8}
\]

The sequence is descending. In finite dimension it stabilizes after at most `n` strict dimension drops at a subspace `V_*`, and

\[
V_*\subseteq\bigcap_\sigma\ker C_\sigma,
\qquad J_\sigma V_*\subseteq V_*\quad\forall\sigma. \tag{9}
\]

Conversely every common invariant subspace inside the common output kernel is contained in each `V_r` and therefore in `V_*`. Thus `V_*` is the largest all-horizon common invisible subspace.

For a constrained finite automaton with state set `A` and edges `e:a->b`, define the monotone operator on a subspace family by

\[
[\mathfrak F(V)]_a=
\bigcap_{e:a\to b}\left[\ker C_e\cap J_e^{-1}V_b\right]. \tag{9a}
\]

Starting from `V_a^(0)=R^n` and iterating `V^(r+1)=F(V^(r))` descends to the greatest invariant family. In a finite automaton the total sum of dimensions can strictly decrease at most `n|A|` times. Equation (8) is the one-state rectangular specialization; a single common subspace is generally conservative for a constrained language.

Equations (8)–(9a) establish same-labelled-mode-word input/output indistinguishability: both states are driven by the identical allowed switching word. They are not a general nondeterministic bisimulation in which different successor modes may be matched. For controlled modes, the action label must be retained or the policy must descend to the quotient.

Longer horizons or a larger lawful continuation tree add constraints, so their invisible spaces can only shrink. Finite-horizon safety never implies all-horizon safety. For example, with a shift register and a read of the first coordinate, a sufficiently delayed coordinate is invisible through horizon `H` and visible at `H+1`.

## 4. Same-prefix impossibility and uncertainty collapse

The repair exposes the cost of being lawful. Suppose two environments have the same prefix and complete state `x=(x_1,x_2)`. In future world A the protected behavior is `x_1`; in future world B it is `x_2`. An oracle told the realized world has a one-dimensional quotient. A prefix-only certificate must be valid for both, so

\[
\mathcal N_A=\operatorname{span}(e_2),\qquad
\mathcal N_B=\operatorname{span}(e_1),\qquad
\mathcal N_A\cap\mathcal N_B=\{0\}. \tag{10}
\]

Therefore an exact write that merges any nonzero direction cannot be certified safe for both futures. The lawful options are to retain both coordinates, avoid/soften the overwrite, obtain additional external evidence, or accept a conditional risk claim. This is an information boundary, not a failure of the recursion.

Likewise, if an ambiguity set contains a full operator-norm ball of output matrices with positive radius, the common kernel is generically `{0}`: for every nonzero `u`, the ball contains a small perturbation whose output on `u` is nonzero. Nontrivial exact robust kernels require structured uncertainty that preserves a common nullspace. That structure is itself a substantive assumption and can amount to assuming the desired quotient. A soft leakage bound is a different approximate claim.

Per-step marginal coverage does not imply simultaneous path coverage. Under the prefix-conditional simultaneous event `E_t` declared above, (7) holds conditionally on `E_t`; outside it there is no guarantee. Repeated or unbounded use requires an anytime/joint coverage argument rather than multiplying informal marginal confidences. Self-generated futures do not supply external coverage evidence.

## 5. Minimal direct ledger and strongest controls

Let `Q_x=O_TP_t` denote the complete protected behavior map from the pre-write state. To augment the destructive update with a linear side code `Mx`, exact recovery of all declared old behavior requires

\[
\ker A_t\cap\ker M\subseteq\ker Q_x. \tag{11}
\]

The smallest number of real side coordinates is

\[
\boxed{r_{lost}=\operatorname{rank}(Q_xK_t).} \tag{12}
\]

Necessity follows because the side code must separate the quotient of `ker A_t` by `ker A_t cap ker Q_x`; its dimension is `rank(Q_xK_t)`. Sufficiency follows by taking an orthonormal basis `U` of `im(Q_xK_t)` and choosing `M=U^TQ_x`, which attains the rank bound. This is a real-linear dimension result, not a finite-bit capacity bound.

The strongest same-information control is therefore ordinary Delta plus this direct pre-write lost-visible ledger, using exactly the same prefix-derived tree, precision, basis metadata and decoder. Other controls are:

1. full joint unrolled JVP/VJP on every represented branch;
2. no-write, partial overwrite or soft preconditioning driven by the same prefix certificate;
3. a direct write/skip/strength predictor using the same prefix features and training feedback;
4. full-state retention when robust uncertainty makes `r_lost=n`.

A prefix-varying quotient basis is not free. If `Q_eta` or a route label varies inside a fiber of `W_t`, the decoder cannot infer it unless it is retained as side state. With `W(s)=s^2` and protected behavior `Phi(s)=s`, local derivatives away from zero have trivial kernel, yet `s` and `-s` merge. Storing the branch/sign is an added ledger. For hard routing, `Phi(s)=1{s>=0}` has derivative zero almost everywhere while a finite overwrite merging `+epsilon` and `-epsilon` destroys the route. A pointwise route margin is insufficient unless uniform over every merged fiber.

## 6. Computation and state accounting

Let `B` be the number of explicitly enumerated lawful suffix branches, `E` the number of tree/automaton edges, `p` the read dimension, `H` the horizon, `m` the number of tested lost directions and `r` a quotient rank.

- An explicitly stacked tree operator can require `O(B H p n)` storage; dense nullspace work is `O(min(B H p n^2,(BHp)^2 n))`. Dense transition products can reach `O(BHn^3)`, while row propagation may reduce the algebraic cost but not the branch count. `B` can grow exponentially with `H`.
- The recursive automaton form avoids explicit path enumeration but stores a subspace per node/state and repeatedly computes intersections and preimages. Dense QR/SVD work is cubic in `n` per edge/iteration in the worst case, with `O(|A|nr)` basis or `O(|A|n^2)` projector storage and a numerical-rank tolerance.
- Matrix-free auditing of `m` threatened directions across represented branches costs `O(BmH)` full-network JVP passes plus rollouts and checkpoint/recompute state. Random or Krylov probes do not certify an exact common kernel.
- Retaining `q=Qx` costs `r` recurrent coordinates, but an explicit prefix-varying `Q` costs `O(nr)` metadata plus decoder/transition/routing state. The direct ledger in (12) has the same basis-information burden and is the matched comparator.

No claimed benefit is established without matching all recurrent state, automaton/estimator parameters, precision, calibration data, inference calls and tokens.

## 7. Nonlinear and state-dependent boundary

For nonlinear dynamics, a prefix-measurable set-valued transition relation and a global equivalence relation are needed for finite-edit safety. A nominal family of Jacobians proves only first-order invisibility. State-dependent reachable-mode sets can be circular: if the set depends on the pre-write state differently within one update fiber, it is not decodable after the write unless that distinction is stored. Disconnected fibers, singular points and discrete routing require a global fiber/right-congruence check.

The exact global condition remains

\[
W_t(x)=W_t(x')\Longrightarrow
\Phi_T(x)=\Phi_T(x') \tag{13}
\]

for every admissible continuation in the prefix-declared relation. Jacobian common kernels are at most local evidence for (13). They do not establish semantic validity, free-running coverage or recursive self-improvement.

## 8. Predictions, old-counterexample recheck and measurement boundary

The repaired theorem yields falsifiable conditional predictions:

1. A realized-branch quotient can be smaller than the prefix-lawful robust quotient; same-prefix complementary future reads force the latter to full rank as in (10).
2. Preserving path constraints can recover a nontrivial quotient that a rectangularized marginal-mode recursion incorrectly removes.
3. Adding admissible branches or extending the horizon cannot enlarge the exact invisible subspace.
4. Whenever `rank(Q_xK_t)>0`, a direct ledger of that many real coordinates is necessary and sufficient in the affine linear class; a purported zero-state repair must be using extra information, accepting error, or changing the target.

All R18 v1 counterexamples survive. Complete-state cross-block paths can turn a memory-only false safety into visible loss; an auxiliary copy can turn memory-block false destruction into joint-state retention; local Jacobian zero does not imply finite nonlinear constancy; hard routing can change despite an almost-everywhere-zero derivative; and a fixed teacher-forced suffix does not certify free-running behavior. V2 only replaces the future-suffix oracle by a conditional prefix object.

Existing native bAbI, LAMBADA, RULER, BABILong and LongMemEval assets can later measure downstream answer/token endpoints. They do not natively expose the prefix-conditioned operator tree, complete-state fibers, common invariant subspace, overwrite/no-write potential outcomes, tree-coverage event or ledger rank. Therefore analytical identities are checkable, but mechanism attribution and empirical effect remain unmeasured. Native success cannot verify the universal branch claim; native failure can only falsify an implementation's endpoint behavior.

## 9. Collision and disposition

The main mathematics is not a new mechanism. Linear switched-system realization/observability already treats noncommuting mode words and minimal observable quotients; robust/common invariant-subspace work already uses intersections and preimages; predictive-equivalence and minimal recurrent-memory work already requires prefix compatibility/right congruence; functional observers and direct sufficient coordinates are strong controls. Data-driven common-invariant identification supplies probabilistic near-invariance, not an exact upgrade from samples.

What remains useful is a Delta-specific repair theorem and no-go boundary:

- lawful certificates must be prefix-measurable;
- constrained mode paths must remain conditioned rather than rectangularized;
- exact robustness can collapse compression;
- probabilistic coverage, nonlinear global congruence, computation and basis state must be charged;
- the direct ledger attains the same affine lower bound.

Thus mathematical status is **conditionally correct for the declared affine tree**, contribution status is **known-mechanism debugging/control**, and empirical status is **unknown with a native measurement gap**. R18 v2 is parked after attempt 2/3 with `candidate_delta=0`.
