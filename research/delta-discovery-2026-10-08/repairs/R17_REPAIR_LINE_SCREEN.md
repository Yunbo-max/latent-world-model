## Decision

R17 performs one substantive revision of the predictive-quotient line. It changes the retention target, not the observed information: exact overwrite need not preserve distinctions that no declared future read or loss can observe. The child therefore proves when the subspace erased by a Delta overwrite lies entirely inside a declared predictive fiber, and then replaces the old full-state Fano bound by conditional rate distortion for the quotient that actually matters.

The repair does not delete the old singularity or equal-codebook counterexamples. If an erased direction is visible to even one allowed future query, exact overwrite still loses behavior; if a split representation decodes only the same quotient under the same total code budget, a direct code can reproduce it. General predictive-fiber, decision-sufficiency and rate-distortion theory are strong collisions, so the expected contribution is a useful Delta-specific theorem/control, not a presumed new method or admitted candidate.
