# 方法思想与当前实现

这份说明对应包含它的源码提交。状态为 **generated_unexecuted**：已做数学和源码检查，测试、训练、原生评测与 GPU 资源测量仍待 Local。采用定义以[扩展规格](../rounds/full-plan-2026-10-08/EXPANSION_SPEC.md)为准；[第二轮复查](../rounds/full-plan-2026-10-08/RECHECK_REVIEW.md)记录实际修复和证据边界。

## 要解决的问题

把长历史全部压进有限容量的连续向量，不保证细节可以准确恢复；保留原文又会增加存储和读取成本。另一个需要分开的量是内部计算次数：对同一段历史多算几次，可以改变预测，却不应把重复计算当作又收到一遍外部信息。

当前构造因此保留两种历史表示，并把历史写入、内部计算、语言表达分成明确的调用阶段。可检验的问题是：在披露原文访问量和实际成本后，这些模块是否改善长历史条件下的文本预测。源码连接完整并不回答这个效果问题。

## 五个实际对象

| 对象 | 当前默认大小 | 用途 |
|---|---|---|
| 压缩状态 \(M\) | 16 个槽，每槽 256 维 | 跨已完成段保留可学习的文本历史表示 |
| 原文事件 \(S\) | 最多 4096 个原始 token，FIFO 淘汰 | 保留可按需回读的精确 token、来源、顺序和摘要 |
| 当前前缀 \(P\) | 少于 256 个尚未提交的 token | 给当前段的下一 token 预测提供直接上下文 |
| 工作区 \(H\) | 每个预测位置一行 256 维 | 临时内部计算；重复更新它不提交新观测 |
| 连续计划 \(Z\) | 每个预测位置一行 128 维 | 形成可保存并单独读出的文本预测瓶颈 |

\(M\) 固定形状，\(S\) 的原文保留量有上限。事件和输入块的防重复摘要会随历史增长，所以整个系统不是恒定内存。来源标记记录谁输入了哪些 token，不认证内容的真实性。

## 从输入到一个输出 token

**1. 编码可见前缀。** Prelude 用因果注意力编码段起始向量 SEG 和当前前缀。训练时可以并行计算全段，但预测位置 \(u\) 只读取目标之前的表示；最后一个真实 token 只在已消费的 writer 路径中可见，不能用来预测自己。SEG 使段首 token 也有一个正常的预测位置。

**2. 按位置回读历史。** 每行只用目标之前最近 32 个 token 做查询，在先前完成的事件中按 token 集合交集排序，同分按新近程度排列。最多取 2 个事件、512 个 token；空查询或无匹配时回退到最近事件。取出的原始 token 使用当前词嵌入、事件排名、段内位置和来源嵌入进入注意力。选择本身不求导，嵌入和神经读取可以求导。每行有自己的检索结果，不能合并未来行的结果供早期行读取。

**3. 在固定信息上计算。** 当前默认 full_loop4 分支先用因果 core 将前缀、旧 \(M\) 和检索结果构成 forcing \(b_u\)，只构建一次，然后执行四次受约束更新：

\[
h_u^{(r+1)}=\tanh(Ah_u^{(r)}+b_u),\qquad
A=\frac{cW}{\max(1,\lVert W\rVert_F)},\quad c=0.9.
\]

固定 \(b_u\) 时，实数运算下 \(\lVert A\rVert_2\le c<1\)，tanh 是 1-Lipschitz，因此这是工作区上的收缩迭代。它约束相同信息条件下的状态扰动，不保证事实正确、词预测更准、浮点误差有界或四步已经充分收敛。reader 的四步不会调用 writer。

另一个配置保留 Transformer 循环：共享 adapter/core 在各步重读固定证据和旧记忆。这个分支没有上述全局收缩保证。二者改变了模型类和实际计算，不能把它们的比较说成只改变了一个谱界。

**4. 形成 \(Z\) 并表达。**

\[
z_u=\tanh(W_z h_u^{(K)}+b_z),\qquad
p(x_u\mid M,S,x_{<u})=
\operatorname{softmax}\!\left(\operatorname{Realize}(Z_{\le u})\right)_u.
\]

Realize 把低维计划升回模型宽度，再通过因果语言模块和绑定词嵌入的词表头。它只接收 \(Z\)，没有绕过瓶颈直接读取原文、\(M\) 或工作区的接口。独立保存的快照包含完整的因果计划序列，并与上下文、参数、tokenizer 和源码身份绑定；单独恢复它可以产生一个下一符号分布。

**当前输出仍然自回归。** 选出一个 token 后，把它加入前缀，再为后一个 token 计算新的计划。这里的 \(Z\) 是每个位置的连续文本预测瓶颈；尚未实现先确定整句语义、再独立生成整句的可逆 codec。语言读出仍包含因果 Transformer 模块。

## 何时写入长期状态

在线接口只有完整的非 EOS 段到达时才提交一次。Writer 使用旧 \(M\) 和已消费段的 Prelude 表示，而不使用最后的推理工作区：

\[
M_t=(1-g_t)\odot M_{t-1}+g_t\odot\widetilde M_t,\qquad
g_t=\sigma(\cdot),\quad\widetilde M_t=\tanh(\cdot).
\]

原文事件同步追加，超出原文容量时 FIFO 淘汰。部分段连同 token 来源保持在 \(P\) 中；EOS 之后重置当前文档的记忆和前缀。输入块重试在 writer 之前核对稳定 ID 和摘要，相同输入不重复写入，冲突输入拒绝。状态保存保留部分前缀、压缩状态、原文事件、摘要和采样 RNG。

Writer 与 \(K\) 无关，所以加深内部计算不会把相同历史写入多次。代价是深层工作区的解释不会直接写回 \(M\)。生成 token 仍会进入返回分支的前缀及完成段的压缩状态；默认过滤只排除原文检索里的 generated 位置。需要保留仅含外部输入的分支时，保留生成前的函数式状态。\(M\) 不能据此被称为经过校准的事实后验。

## 三个时钟

| 计数 | 何时前进 | 表达的区别 |
|---|---|---|
| 观测 | 接纳 observed_text token | 收到了新的输入 |
| 推理 | 执行显式 plan 或生成的内部步骤 | 在已有信息上继续计算 |
| 表达 | 生成一个 token | 形成了新的输出历史 |

这三个计数不是完整的性能 profiler；纯读取和临时似然分支另由实际调用统计、耗时和资源记录计量。重复推理不增加观测计数，生成内容也不会被改标为外部观测。

## 如何训练

主目标为正常的因果文本交叉熵。段内同一行的 logits 预测该行的真实 token，不能再次移动 labels。可选的辅助头仅从上一完整段写入后的 \(M\)，预测同文档下一段的**第一个 token，且只在该位置本身属于监督目标时计算**；不会越过被 mask 的段首去寻找后面的标签。

\[
\mathcal L=
\frac{\sum_{\text{eligible }u}-\log p_\theta(x_u\mid M,S,x_{<u})
+\beta\sum_{\text{eligible successor pairs}}-\log q_\theta(x_{\mathrm{next},0}\mid M_t)}
{N_{\mathrm{main}}},\qquad \beta=0.1.
\]

辅助目标只在 loss 中使用，不能提前进入状态或检索。主目标数、辅助配对数、主文本 NLL 和复合目标分别记录。这个有限目标鼓励 \(M\) 保存对后续预测有用的信息，不等价于已经证明它包含完整未来所需的一切信息。

TBPTT 窗口默认为四段：窗口内保留连续状态的计算图，让后续段损失训练前面段的 writer；只在窗口边界 detach。文档结束则真正 reset，二者不同。默认累计 8192 个 eligible 主目标再进行优化。FP16/GradScaler 跳过的更新仍计入已经看到的目标，不能算成完成了参数更新。实际数值和恢复行为仍需 Local 测试。

## 实验要回答什么

现有设计用完整 bAbI 20 任务 / 20000 问题和 LAMBADA 5153 条，分别检查压缩历史、内部深度、原文读取、计划瓶颈、状态辅助目标和两种循环。原文检索提供额外信息，不能把它的收益全部归因于压缩；模块移除和循环替换也改变活跃参数及计算，应报告实际成本。

13 arms、2 seeds 的 100M / 1B 表示每个预训练运行的目标 token 预算，整组为 2.6B / 26B，另加各组 26M bAbI 适配目标及上下文、验证、评测和失败成本。尚无本次修复的运行结果、吞吐测量或完整矩阵结论。

当前源码实现的是有持久状态、原文回读和内部迭代的文本预测构造。预测充分性、可逆句级语义、真实动作/物理世界动力学、自适应停止证书、原创性和实际收益仍需各自的理论、数据和实验支持。
